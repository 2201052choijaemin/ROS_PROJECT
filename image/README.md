# 블럭도

![블럭도](block_diagram.png)

본 작품의 기능을 10개의 블럭으로 나누어 표현하였다. 각 블럭은 하나의 기능을 의미하며, 화살표는 데이터가 흐르는 방향, 화살표 위의 글자는 주고받는 데이터를 의미한다.

## 1. 세부 기능 정의

| 번호 | 블럭(기능) | 위치 | 입력 데이터 | 출력 데이터 | 설명 |
|---|---|---|---|---|---|
| ① | 키보드 입력 | PC | 사용자 키 입력 | 키 입력 문자 (f·b·l·r·s) | 사용자가 PC 키보드로 이동 명령을 입력한다. |
| ② | 이동 명령 발행 | PC (ROS 2) | 키 입력 문자 | 이동 명령 메시지 (Twist) | 키 입력을 ROS 2 이동 명령 메시지로 변환하여 `/rc_car/cmd_vel` 토픽으로 발행한다. (Publisher) |
| ③ | 이동 명령 전달 | PC (ROS 2) | 이동 명령 메시지 (Twist) | Wi-Fi 동작 명령 | 토픽을 구독하여 메시지를 해석하고, 전진·후진·회전·정지 명령을 Wi-Fi로 RC카에 전송한다. (Subscriber) |
| ④ | 웹 제어판 | 스마트폰 · PC 브라우저 | 버튼 터치, 실시간 영상 | Wi-Fi 버튼 명령 | 스마트폰이나 PC의 인터넷 창(웹 브라우저)에서 버튼으로 RC카를 조종하고, 실시간 영상을 확인한다. |
| ⑤ | 명령 수신·해석 | ESP32-CAM | Wi-Fi 동작 명령 / 버튼 명령 | 방향·속도 값, LED 켜기/끄기 신호 | Wi-Fi로 받은 명령이 어떤 동작인지 판단한다. |
| ⑥ | 모터 제어 | ESP32-CAM | 방향·속도 값 | 모터 신호 (PWM) | 바퀴의 회전 방향과 속도에 맞는 모터 제어 신호를 생성한다. |
| ⑦ | 영상 촬영 | ESP32-CAM | RC카 전방 장면 | 사진 (JPEG 이미지) | 카메라로 RC카 앞을 연속 촬영한다. |
| ⑧ | 영상 송출 | ESP32-CAM | 사진 (JPEG 이미지) | 실시간 영상 (MJPEG) | 촬영한 사진을 연속으로 전송하여 스마트폰·PC 화면에 실시간 영상으로 보여준다. |
| ⑨ | 바퀴 구동 | RC카 구동부 | 모터 신호 (PWM) | 바퀴 회전 → RC카 주행 | 모터 드라이버(L298N)가 좌/우 DC 모터를 회전시킨다. |
| ⑩ | LED 점등 | RC카 구동부 | LED 켜기/끄기 신호 | 빛 (전조등 ON/OFF) | RC카의 LED를 켜거나 끈다. |

## 2. 데이터 흐름

- **주행 제어 흐름 (PC)**: ① 키보드 입력 → ② 이동 명령 발행 → ③ 이동 명령 전달 → ⑤ 명령 수신·해석 → ⑥ 모터 제어 → ⑨ 바퀴 구동
- **주행 제어 흐름 (스마트폰 · PC 브라우저)**: ④ 웹 제어판 → ⑤ 명령 수신·해석 → ⑥ 모터 제어 → ⑨ 바퀴 구동
- **LED 제어 흐름**: ⑤ 명령 수신·해석 → ⑩ LED 점등
- **영상 흐름**: ⑦ 영상 촬영 → ⑧ 영상 송출 → ④ 웹 제어판 (스마트폰 · PC 화면)
